# 퀴즈 마스터

고등학교 통합과학2·통합사회2·한국사2 퀴즈 게임입니다. 각 과목 5문제, 총 15문제이며 정답마다 10점을 받습니다.

## 실행 방법 (3단계)
1. 압축파일을 풀어 `Quiz-Master` 폴더를 준비합니다.
2. 7개 파일을 모두 같은 폴더에 둡니다.
3. `index.html`을 더블클릭해 브라우저에서 실행합니다.

## 파일별 역할
- `index.html`: 학생용 시작·퀴즈·결과 화면
- `style.css`: 청록·파랑·주황 강조색과 반응형 디자인
- `questions.js`: 3개 과목 문제 데이터 (새 문제 추가 가능)
- `script.js`: 문제 순서 섞기, 채점, 점수 계산, 결과 저장
- `admin-report.html`: 관리자 보고서 화면
- `admin-report.js`: 응시 기록·평균 통계·기록 삭제
- `README.md`: 실행 및 배포 안내

## 문제 추가하기
`questions.js`의 `QUIZ_QUESTIONS` 배열에 다음 객체를 쉼표로 구분해 추가하세요.

```javascript
{
  category: '통합사회2',
  question: '문제 내용',
  options: ['선택지1', '선택지2', '선택지3', '선택지4'],
  correctAnswer: 0,
  explanation: '정답 해설'
}
```

정답 위치는 첫 번째부터 `0, 1, 2, 3`입니다. 문제 수와 카테고리 통계는 자동 계산됩니다.

## GitHub Pages 배포
1. GitHub에서 공개 저장소 `quiz-master`를 만듭니다.
2. 압축을 푼 폴더 **안의 7개 파일**을 저장소 최상위에 업로드하고 Commit합니다.
3. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save를 선택합니다.
4. 배포 주소는 일반적으로 `https://사용자이름.github.io/quiz-master/`입니다.

## 기록 저장 관련 주의
응시 기록은 `localStorage`에 저장됩니다. 따라서 **같은 브라우저의 기록만** 관리자 보고서에서 볼 수 있습니다. 학생들이 서로 다른 기기에서 응시한 결과가 한곳에 모이지는 않습니다. 관리자 보고서에 로그인이나 접근 제한 기능은 없습니다. 브라우저 데이터 삭제 또는 저장 제한 시 기록이 사라지거나 저장되지 않을 수 있습니다. `file://`에서 저장이 제한되는 브라우저라면 GitHub Pages 주소나 로컬 서버에서 실행하세요.
